# z/config/

Конфигурация серверной части. **Папка защищена `.htaccess` от веб-доступа.**

## Что здесь

- `.htaccess` — запрет доступа из браузера (`Require all denied`).
- `.env.example` — шаблон с именами переменных, без секретов. В git.
- `.gitignore` — исключает `.env` из git.
- `.env` — реальные креды (создаётся на сервере из `.env.example`, **не коммитится**).

## Деплой на сервер

1. Загрузи `.htaccess` в `public_html/z/config/`.
2. Загрузи `.env.example`, переименуй в `.env`, заполни реальными значениями.
3. Убедись, что `.htaccess` загрузился (скрытый файл — включи «показывать скрытые» в файловом менеджере).

## Проверка защиты

Открой в браузере `https://slqa.ru/z/config/.env` — должен быть `403 Forbidden`.
Если видишь содержимое файла — `.htaccess` не сработал, проверь, что он загрузился и `AllowOverride` разрешает `AuthConfig` (обычно да на shared).

## Как PHP находит `.env`

`z/api/env_loader.php` читает `__DIR__ . '/../config/.env'` — то есть `z/config/.env` относительно `z/api/`.
